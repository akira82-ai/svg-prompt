# archive/demos — 14 个技术验证 Demo（已归档）

这批 Demo 是项目立项前的**技术验证**：验证纯 SVG（零 JS）的动效天花板与复杂架构图可行性，全部经浏览器渲染逐张验收。它们不是图鉴条目，不参与五维标签体系，仅作存档。

打开 `index.html` 可一次性浏览全部。13、14 号由仓库内 Node 脚本 `_gen13.mjs` / `_gen14.mjs` 生成。

| # | 文件 | 内容 | 验证结论 |
|---|---|---|---|
| 01 | 基础图形 | 七大形状、stroke/fill、坐标系 | 基础无坑 |
| 02 | 渐变与玻璃质感 | 线性/径向渐变、玻璃拟态 | 可行 |
| 03 | 程序化纹理与图案 | pattern 平铺、滤镜纹理 | 可行 |
| 04 | 复杂系统架构图 | 6 分区 20 节点正交折线 | **复杂架构图可行**（坑：连线必须正交折线） |
| 05 | 描边动画 | dashoffset 线稿"被画出来" | CSS 层动效可行 |
| 06 | SMIL 动效面板 | `<animate>` 内嵌，单文件自包含 | SMIL 零依赖动图可行 |
| 07 | 滤镜特效 | feTurbulence、gooey、3D 打光 | 滤镜材质层可行 |
| 08 | 动态架构图 | 架构图 + 数据包流动 + 心跳灯 | **动效天花板：SMIL 可撑起仪表级动图** |
| 09 | 数据可视化仪表盘 | 多图表组合 | 可行 |
| 10 | SVG 黑科技 | mask/clip/foreignObject | 可行 |
| 11 | 变形记 Morph | 路径形变动画 | 可行（点数需一致） |
| 12 | 变形记 II | Morph 进阶 | 可行 |
| 13 | 三维 | 迷你 3D 引擎投影（脚本生成） | **手写坐标不可行，须脚本生成** |
| 14 | 数学变换 | 球面⇄环面拓扑、莫比乌斯带（脚本生成） | 同上 |

**踩坑记录**：
- 水平/垂直线段上 `objectBoundingBox` 渐变会退化（宽或高为 0），需改用 `gradientUnits="userSpaceOnUse"`。
- Morph 两端 path 的锚点数必须一致，手写对齐困难，建议脚本生成。
- 超过 ~20 节点的架构图靠模型盲算坐标必翻车，正交折线 + 分区布局是底线。
