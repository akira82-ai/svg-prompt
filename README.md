# svg-prompt

> **AI 生成 SVG 的图形图鉴** —— 每个作品都带可复制的提示词咒语。
> Every SVG ships with its prompt.

GitHub 上从不缺 SVG 画廊：[svg-spinners](https://github.com/n3r4zzurr0/svg-spinners)（7k★）、[logos](https://github.com/gilbarbara/logos)（6.8k★）、[Hover](https://github.com/cevadtanca/burger-hover-effects)、[awesome-svg](https://github.com/willianjusten/awesome-svg)……但它们全是"平铺画廊 / 链接清单"——**你看得见作品，拿不到让它诞生的提示词**。

本项目把两者耦合在一起：**每个条目 = 可视 SVG 作品 + 可复制提示词模板 + 结构化标签**。调研了 GitHub 全站后确认：这么做的仓库，此前不存在。

## 🧭 五维标签体系

每个图鉴条目用五个维度描述：

| 维度 | 取值 | 说明 |
|---|---|---|
| **空间** | 2D / 3D | 是否使用三维投影、光照、拓扑变换 |
| **时间** | 静态 / 动效 | 动效分三层：SMIL 内嵌（零依赖）→ CSS 描边/过渡 → 滤镜材质 |
| **主分类** | 8 类（见下） | 作品题材归属 |
| **难度** | L1–L6 | 从基础形状到拓扑形变的实现难度 |
| **咒语等级** | L1 / L2 / L3 | 复现该作品所需的提示词复杂度：L1 一句话直出 · L2 结构化模板 · L3 系统化流水线（语义 JSON → 布局引擎 → 渲染） |

> 「咒语等级」是本项目的首创维度：同样的图形，用多复杂的咒语才能让 AI 稳定复现，本身就是图鉴要回答的问题。

## 🗂️ 八大主分类

1. **图表报表** — 架构图、仪表盘、流程图（继承 [Data-to-Viz](https://www.data-to-viz.com/) 与 FT Visual Vocabulary 分类）
2. **信息可视化** — 关系图、地图、层级图
3. **实物模拟** — 玻璃、金属、木纹、光影等材质拟真
4. **高级数学** — 参数曲线、拓扑形变、分形、3D 投影
5. **动效艺术** — 描边动画、Morph、gooey、滤镜动效
6. **UI 组件** — 按钮、图标、加载器、输入控件
7. **品牌排版** — Logo、徽章、文字特效、图案纹理
8. **教学基础** — 形状、坐标系、渐变、路径等入门原型

### docs/research-notes.md — 研究底稿

SVG 能力地图（规范层全梳理）、高级玩法精选、Agent × SVG 实践流派、W3C SVG 2 新特性。核心洞见：

> **LLM 擅长描述图是什么，不擅长决定东西在哪。** 工程解法：模型只输出语义 JSON → 确定性布局引擎（ELK/d3）算坐标 → resvg 渲染 → Schema 校验回喂。
