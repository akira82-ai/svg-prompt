分类：[数据图表](../_about.md)

<img src="index.svg" width="720" alt="延迟箱线图">

```
用 SVG 制作“延迟箱线图”，主题为与直方图共用 30 次请求 / Tukey 须线。
- 画布 1200×800，背景 #0d1724；标题 32px、正文 17–18px、轴标签不小于 15px；主图区留白，不使用装饰性发光。
- 图中重点结论：“中位数 123 ms；215 与 260 ms 被识别为离群值”。
- 数据集与延迟直方图一致：[88, 92, 95, 98, 102, 106, 108, 110, 112, 114, 115, 116, 118, 120, 122, 124, 126, 128, 130, 132, 135, 138, 142, 146, 150, 156, 164, 178, 215, 260]。
- 分位数使用线性插值索引(n−1)p；Q1=110.5，中位数=123.0，Q3=141.0，IQR=30.5。
- Tukey阈值Q1−1.5IQR和Q3+1.5IQR；须端为阈值内实际最小/最大值88/178，不把须端写成全样本min/max；离群点215/260。
- 底部注明“模拟数据 · 用于图型演示，不代表真实产品或行业结论”；所有量纲、刻度、图例与数据对应。
```
