用 SVG 制作“延迟直方图”，主题为30 次模拟请求 / 延迟分布。
- 画布 1200×800，背景 #f3f5f7；标题 32px、正文 17–18px、轴标签不小于 15px；主图区留白，不使用装饰性发光。
- 图中重点结论：“多数请求落在 100–140 ms；右侧存在长尾”。
- 数据集 [88, 92, 95, 98, 102, 106, 108, 110, 112, 114, 115, 116, 118, 120, 122, 124, 126, 128, 130, 132, 135, 138, 142, 146, 150, 156, 164, 178, 215, 260]；每箱20ms，区间[80,100)、[100,120)…，最后一箱[260,280]含右端点。
- 10箱频数[4, 9, 9, 4, 2, 0, 1, 0, 0, 1]，总计30；Y轴人数0–10，柱高=频数×35px，等宽箱紧密排列。
- 底部注明“模拟数据 · 用于图型演示，不代表真实产品或行业结论”；所有量纲、刻度、图例与数据对应。
