```
用 SVG 制作“矩形树图”，主题为基础设施预算 / 父类份额与子项。
- 画布 1200×800，背景 #f3f5f7；标题 32px、正文 17–18px、轴标签不小于 15px；主图区留白，不使用装饰性发光。
- 图中重点结论：“矩形面积对应预算份额；子项面积在各自父类内比较”。
- 五父类份额34/22/18/14/12%，总量100；整体绘图区880×340px。
- 左列宽56%，上下高度34/56与22/56；右列宽44%，三块高度18/44、14/44、12/44，父面积严格对应份额。
- 计算父类内等分3子项，其余父类内等分2子项；不扣除标题区而改变子项比例，子项百分比为父类内部占比，细描边分隔。
- 底部注明“模拟数据 · 用于图型演示，不代表真实产品或行业结论”；所有量纲、刻度、图例与数据对应。
```
