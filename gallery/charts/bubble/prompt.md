# 三变量气泡图 `静态` `2D`

分类：[数据图表](../_about.md)

<img src="index.svg" width="720" alt="三变量气泡图">

```
用 SVG 制作“三变量气泡图”，主题为增长率 × 毛利率 × 市场规模。
- 画布 1200×800，背景 #f3f5f7；标题 32px、正文 17–18px、轴标签不小于 15px；主图区留白，不使用装饰性发光。
- 图中重点结论：“位置编码两个比例；气泡面积编码模拟市场规模”。
- 数据(产品,增长%,毛利%,规模)：[["A1", 10, 72, 20], ["A2", 25, 65, 40], ["A3", 45, 54, 80], ["B1", 20, 42, 30], ["B2", 40, 34, 60], ["B3", 62, 26, 100], ["C1", 68, 74, 25], ["C2", 82, 58, 50], ["C3", 92, 40, 15]]。
- 所有气泡含尺寸图例使用r=4√规模，因此面积=16π×规模；X、Y轴均0–100%，不使用半径直接编码规模。
- 绘图区680×330px，图例右置，不掩盖数据；产品线按色分组。
- 底部注明“模拟数据 · 用于图型演示，不代表真实产品或行业结论”；所有量纲、刻度、图例与数据对应。
```
