# 桑基图 `静态` `2D`

分类：[数据图表](../_about.md)

<img src="index.svg" width="720" alt="桑基图">

```
用 SVG 画一张"个人月度收支桑基图"：
- 左列三个收入节点（竖条）：月薪 25000 / 副业 8000 / 理财 4000
- 中列一个汇聚节点：可支配 37000
- 右列四个支出节点：房租 8000 / 餐饮 5000 / 储蓄投资 12000 / 弹性消费 12000
- 节点间用贝塞尔飘带连接，飘带宽度与金额成正比，按收入来源着色
- 每个节点标注名称与金额
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
```
