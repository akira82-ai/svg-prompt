# 数据图表 · charts

用数据表达比较、趋势、分布、相关、占比和数量流动。按分析任务浏览，动画变体紧随对应静态图。

**收录标准**：收录统计图型、数据编码和组合图；以操作界面为主的仪表盘归界面与组件，地理编码归地图与空间，系统连接归流程与架构。

**标签**：静态或动态由 `time` 标注，空间形式由 `space` 标注，技术由 `tech` 标注；每张图只有一个主分类。

**展示顺序**：比较与排名 → 趋势与变化 → 分布与不确定性 → 关系与多变量 → 构成与流动 → 项目排期。动画只揭示固定数据，不以无依据的几何起伏制造数据变化。

**数据约定**：所有示例数据明确标为模拟；几何位置、面积、角度与数值按同一公式计算。统计图说明分箱、分位数、估计方法与区间假设；不把相关性解释成因果。

**维护**：`python3 scripts/build-charts.py` 根据显式模拟数据重建本类31个作品（三件套），再运行 `node scripts/build-readme.mjs` 和 `python3 scripts/check-charts.py`。调整数据或图形时先改生成脚本，避免下次生成覆盖手工修改。
