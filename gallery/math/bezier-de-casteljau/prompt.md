# 贝塞尔构造动画 `SMIL 动效` `2D`

<img src="index.svg" width="720" alt="贝塞尔构造动画">

```
用 SVG 做"三阶贝塞尔构造动画"：
- 四个控制点构成控制多边形（灰虚线），光点沿贝塞尔曲线行进
- 固定灰色控制多边形、绿色Q点与连线、橙色R点与连线、粉色B点，逐层插值不做呼吸显隐
- 曲线本体蓝色描边
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
- P0=(200,560), P1=(420,220), P2=(780,620), P3=(1000,240)；Qj=lerp(Pj,Pj+1,t)，Rj=lerp(Qj,Qj+1,t)，B=lerp(R0,R1,t)。t在6秒内从0到1，按201帧预计算同一时间的线与点，禁止用等速animateMotion替代参数t。
```
