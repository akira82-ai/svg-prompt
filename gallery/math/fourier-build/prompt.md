# 傅里叶构建动画 `SMIL 动效` `2D`

<img src="index.svg" width="720" alt="傅里叶构建动画">

```
用 SVG 做"傅里叶逼近构建动画"：
- 目标方波（灰虚线）固定，逼近曲线从 1 项开始按档加入谐波：N按1/3/5/7/9/13/21档切换，前6档各1秒，最后档2秒，8秒循环
- 每档曲线颜色亮度递增，项数计数器同步
- 最后一档停留2秒后重新开始
- 深底 #0b101d，青色曲线
- 计算：fN(x)=4/π∑[k=1..N]sin((2k−1)x)/(2k−1)，x∈[0,2π]，501点，屏幕幅度90；曲线与N标签按互斥离散opacity切换，虚线为sign(sin x)目标方波。
```
