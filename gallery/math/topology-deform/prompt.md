```
用 SVG 展示 3D 参数之舞（线框渲染：深底 #0b101d + 蓝/青/金彩色线框，1200×800 四面板）：
- 球面 ⇄ 圆环面：同一副 (u,v) 网格，环面主半径 R 62→44→26→10→0，参数像连续退化，R=r时有奇点，0<R<r是自交纺锤面，R=0像覆盖球面但参数化不正则；不保持拓扑等价
- 莫比乌斯带：线框网格渲染（三条蓝/青描边 path：边缘曲线 + 侧面斜线），标注"只有一条边"
- 利萨茹曲线（x=sin3t、y=sin4t、z=sin5t）与水面涟漪（z=A·sin(k·r−ωt)·e^(−r/70)）
- "变换的通用配方"卡：①–⑤ 步骤 + 球化环 R 序列注释 + "换一个方程=换一种宇宙"
- 关键帧密集、样条缓动
- 环面模型：((R+r cos v)cos u,(R+r cos v)sin u,r sin v)，r=26，u,v∈[0,2π]。莫比乌斯带：((1+(v/2)cos(u/2))cos u,(1+(v/2)cos(u/2))sin u,(v/2)sin(u/2))，u∈[0,2π],v∈[-1,1]。
```
