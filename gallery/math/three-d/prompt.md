# 三维投影 `SMIL 动效` `3D`

<img src="index.svg" width="720" alt="三维投影">

```
用 SVG 表现 3D，四个动画面板 + 一张边界说明卡（1200×800 深底）：
- 等距数据中心：RACK-A·42U / RACK-B·36U 机柜、三色 LED 心跳（绿/黄/红闪烁点）、等距浮动小服务器与投影
- 圆环面线框：20 条线按深度调 opacity，金色 #ffd166 主视线环
- 立方体 90° 翻面：12 段 path 的 d 插值 + 顶点光点 cx/cy 分轴动画（calcMode spline）
- 3D 柱状图摇摆：相机绕轴摆动、面片 points 逐帧插值
- 边界说明卡：等距是伪 3D、动态 3D 是关键帧预计算，可拖拽的真 3D 才需要 WebGL
- 画布 1200×800
```
