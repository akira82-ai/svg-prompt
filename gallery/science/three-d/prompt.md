分类：[科学与原理](../_about.md)

```
用 SVG 制作“三维投影 · 同物体对照”：同一单位立方体 / 正交、透视、等距投影。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：三个面板使用同一组顶点和边；投影方式改变画面，不改变物体结构。
- 顶点(±1,±1,±1)的12条边；正交相机先绕Y轴30°：u=cos30°x+sin30°z，d=−sin30°x+cos30°z；再俯仰20°：v=cos20°y−sin20°d，depth=sin20°y+cos20°d；透视(U,V)=4(u,v)/(4+depth)，相机距离4。
- 等距u=(x−z)/√2、v=(2y−x−z)/√6；三坐标轴相同缩短率，不是随意斜画；三个面板100px/投影单位，全部边显示无隐藏线处理。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
```
