# 科学与原理 · science

用图形解释数学构造、科学模型和计算过程，共 16 张。按曲线与构造 → 迭代与逼近 → 波动与光学 → 轨道与投影 → 曲面与优化排列，静态与对应动画相邻。

**收录标准**：主图承担解释任务，明确公式、参数、坐标范围与关键结论；动画由共同模型参数驱动，不将装饰运动当作机制解释。纯装饰曲线归几何与生成艺术，科幻特效归插画与场景。

**模型边界**：斐波那契圆弧近似不等于黄金对数螺旋；有限分形图不表示无限细节；傅里叶增加项数不能消除吉布斯超调。驻波是等幅反向行波的线性叠加；薄透镜为近轴理想模型，图中高度为教学夸张。开普勒轨道使用均匀平近点角解方程；太阳系为圆轨道简化，半径压缩、尺寸与相位不按真实星历。

**来源与验证**：行星近似半长轴参考 [NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)（2026-10-10 核查），模型周期由 T²=a³ 计算，不作为精确观测值。其余曲线、波动、透镜和优化示例由条目中的显式方程生成，并使用独立恒等式验证实际 SVG 几何。

**曲面与投影**：同一立方体比较正交、透视和等距投影，不做隐藏线消除。莫比乌斯带展示半扭转与一条边界，不宣称环面能变成莫比乌斯带；固定线框投影不表示遮挡关系。梯度下降只说明给定凸二次函数与步长的行为。

**维护**：修改 `scripts/build-science.py` 后生成三件套，运行 `scripts/check-science.py`，再检查浏览器动画取样、减少动效和全部文字布局。SMIL 样本间插值是近似；减少动效显示明确参数下的完整静态快照。原有目录名保留，以兼容已有引用。

**标签**：时间、空间形式与技术分别使用 `time`、`space`、`tech`；每张图只有一个主分类。
