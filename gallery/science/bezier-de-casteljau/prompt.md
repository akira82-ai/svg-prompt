分类：[科学与原理](../_about.md)

```
用 SVG 制作“贝塞尔曲线 · 逐层构造”：三次曲线 / 共同参数 t / De Casteljau 算法。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：每层使用同一个 t 做线性插值；最终点始终位于三次贝塞尔曲线上。
- 控制点[[150, 650], [280, 305], [670, 310], [820, 650]]，所有辅助线和点共用121个t样本0→1→0，周期10s；三次曲线取401点。
- 减少动效显示t=.5的完整Q/R/B构造；SMIL样本间线性插值为近似，样本时刻严格满足递推关系。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
- 动画使用SMIL预计算取样，不引入脚本；同一构造中的全部动画共同起点、时长和参数序列。减少动效模式隐藏motion组，显示完整fallback静态快照；动效不改变数值编码。
```
