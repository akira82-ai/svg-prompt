```
用 SVG 制作“梯度下降 · 步长与收敛”：f(x,y) = x² + 3y² / η = 0.2 / 起点 (2,1.5)。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：沿负梯度更新，损失逐步下降；步长过大仍可能发散，不能只看箭头方向。
- 函数x²+3y²，梯度(2x,6y)，起点(2,1.5)，η.2，10步显式迭代(x,y)→(.6x,−.2y)，每步标记损失。
- 等高线.25/1/3/6/9，椭圆参数(√c cosθ,√(c/3)sinθ)，绘图区x±2.5、y±2；绘图窗口以外等高线须裁切。
- Hessian diag(2,6)，收敛条件0<η<2/6；η≥1/3不能保证收敛，此凸二次例不推广到非凸损失。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
```
