```
用 SVG 制作“谢尔宾斯基三角形”：递归挖空 / 迭代 0、1、2、4 阶。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：每阶保留 3 倍小三角；边长减半，保留面积乘 3/4。
- 四面板迭代0/1/2/4阶；每步连接边中点，保留三个角三角；数量3ⁿ，面积比例(3/4)ⁿ，不能将有限渲染称为无限细节。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
```
