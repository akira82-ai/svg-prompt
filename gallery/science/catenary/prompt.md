分类：[科学与原理](../_about.md)

```
用 SVG 制作“悬链线与抛物线”：相同跨度、端点高度与最低点 / 无量纲坐标。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：两曲线共享端点和最低点，但中间形状不同；悬链线对应均匀柔索自重。
- 绘图区x−2..2、y0..3；蓝y=cosh(x)−1，绿y=(cosh2−1)x²/4，两者端点和最低点一致。
- 悬链线条件：均匀柔索、自重静力平衡、忽略弯曲刚度；抛物线对应按水平投影均布的竖向荷载，不说所有悬索都是抛物线。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
```
