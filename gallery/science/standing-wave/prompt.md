```
用 SVG 制作“驻波 · 节点与腹点”：两列等幅反向行波 / 无量纲 x ∈ [0, 2π]。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：等幅反向波叠加形成驻波：节点固定，腹点振幅为单列波的两倍。
- y₁=sin(x−t)、y₂=sin(x+t)，共同48段相位周期2π、视觉周期6s；合成y=2sinx cos t，振幅范围±2，X0..2π。
- 驻波节点x0/π/2π不移动，腹点π/2与3π/2振幅2；虚线包络±2|sinx|；这是理想一维无耗散线性波，不表示介质质点沿波传播。
- 动画逐帧同参采样，样本间插值近似；减少动效快照t0。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
- 动画使用SMIL预计算取样，不引入脚本；同一构造中的全部动画共同起点、时长和参数序列。减少动效模式隐藏motion组，显示完整fallback静态快照；动效不改变数值编码。
```
