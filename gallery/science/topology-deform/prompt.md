```
用 SVG 制作“莫比乌斯带 · 半扭转构造”：参数曲面 / θ ∈ [0, 2π] / v ∈ [−0.35, 0.35]。
- 画布1400×900，深色底、34px标题、17–18px说明、14px刻度；蓝色主模型、绿色对照、橙色重点。
- 主结论：绕行一圈，横向坐标反向；边界只有一条闭合曲线，不是环面形变。
- 莫比乌斯嵌入p(θ,v)=((1+v cos(θ/2))cosθ,(1+v cos(θ/2))sinθ,v sin(θ/2))，v±.35；13纵向曲线与49横向线段；固定线性投影。
- 接缝p(2π,v)=p(0,−v)，橙色边界固定v.35让θ0..4π一圈闭合；该窄带单侧、单边界，不宣称环面可连续变成莫比乌斯带；全部网格显示，不作遮挡。
- 理想化教学模型；明确参数、坐标范围与近似条件，不伪装成实验观测。
```
