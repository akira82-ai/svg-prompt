# 时间轴点亮 `SMIL 动效` `2D`

<img src="index.svg" width="720" alt="时间轴点亮">

```
用 SVG 做"时间轴点亮动画"：
- 中央竖向时间线自上而下逐段点亮（stroke-dashoffset 循环）
- 6 个事件节点随线到达依次亮起（圆点+年份+事件名 opacity 循环，begin 递增）
- 全部亮完停留 1 秒后归零重来
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
- 历史口径：W3C REC-SVG-20010904、REC-SVG11-20030114、REC-SVGTiny12-20081222、REC-SVG11-20110816、CR-SVG2-20160915、CR-SVG2-20181004；候选推荐、草案不等于正式推荐，也不代表浏览器全面支持。
```
