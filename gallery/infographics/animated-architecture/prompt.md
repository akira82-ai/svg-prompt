# 动态架构图 `SMIL 动效` `2D`

<img src="index.svg" width="720" alt="动态架构图">

```
用 SVG 画一张"会呼吸"的系统架构图：
- 与静态版同一张六分区架构图（客户端×3 / 接入×3 / 微服务×6 / 中间件×4 / 数据×4 + OPS 列），正交折线布线
- 数据包流动：每条连接线上放小圆 <animateMotion> 沿真实布线 path 移动，各链路 begin 错开
- 心跳灯：微服务层 opacity 1↔0.25 呼吸 dur 2s begin 错开，中间件层半径脉冲，数据层呼吸时长各异
- 标题流光：渐变 x1/x2 循环平移制造扫光
画布 1600×1000 深色底。
```
