# 树状图 Treemap `静态` `2D`

<img src="index.svg" width="720" alt="树状图 Treemap">

```
用 SVG 画一张"手机市场份额树状图"：
- 大矩形分割为五个品牌区块：星芒 34%（蓝，内分 3 子块）、流光 22%（紫，2 子块）、磐石 18%（绿）、晨曦 14%（橙）、其他 12%（灰）
- 每个区块标品牌名与百分比，大区块内再分子型号小块
- 右侧标注总规模
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
- 数据为虚构：总量10亿台，五类份额34/22/14/18/12%；父块面积严格按份额分区。每父块扣除标题与边距后，型号子区等分铺满：星芒3份，其余各2份；不允许重叠，子份额为父块内部比例。
```
