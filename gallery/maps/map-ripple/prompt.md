# 地图涟漪 `SMIL 动效` `2D`

分类：[地图与空间](../_about.md)

<img src="index.svg" width="720" alt="地图涟漪">

```
用 SVG 做"区域版图涟漪地图"：
- 六大区域色块组（同静态版式）作为底图
- 五个城市（北京/上海/杭州/广州/重庆，锚定京/沪/浙/粤/渝格中心）位置放光点，每个光点外两圈涟漪持续扩散（r 变大、opacity 渐隐，begin 错开），强度按涟漪大小分档
- 右侧图例：涟漪最大半径 = 模拟业务量三档，14/20/26；非面积数值编码
- 动画无限循环
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
```
