```
用 SVG 制作“区域事件分布”：虚构园区 / 同一事件快照。
- 画布1400×900，背景#0d1724；标题34px、正文17–18px、刻度14–15px。重点结论：“固定圆面积编码事件次数；涟漪仅吸引注意，不编码业务量”。
- 虚构园区平面笛卡尔坐标，X轴0–600m、Y轴0–400m，北向上；绘图区x=140..860、y=305..785，比例1.2px/m，X/Y必须同尺度。
- 事件(ID,x米,y米,次数)：[["E1", 110, 100, 9], ["E2", 330, 270, 16], ["E3", 480, 205, 4]]；固定圆面积=36π×次数。
- 静态/动态使用完全相同事件标记、坐标、数值与标签；动态版每个强调圈初始半径相同20px。
- 页脚明确：“模拟业务数据 · 空间示意不代表实际服务或运营结果”。
```
