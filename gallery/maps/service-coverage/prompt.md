```
用 SVG 制作“直线距离服务覆盖”：虚构园区 / 半径 140m 与 130m。
- 画布1400×900，背景#0d1724；标题34px、正文17–18px、刻度14–15px。重点结论：“6 个测试点中 3 个在覆盖内；不是通行时间、无线信号或容量预测”。
- 虚构园区平面笛卡尔坐标，X轴0–600m、Y轴0–400m，北向上；绘图区x=140..860、y=305..785，比例1.2px/m，X/Y必须同尺度。
- 服务点(ID,x,y,半径m)：[["S1", 170, 180, 140], ["S2", 410, 220, 130]]；测试点：[["P1", 60, 80], ["P2", 220, 260], ["P3", 300, 200], ["P4", 490, 300], ["P5", 560, 70], ["P6", 100, 340]]。
- 判定min距离：任一sqrt((x−cx)²+(y−cy)²)≤r即覆盖，两个圆交集只计一次。
- X/Y都1.2px/m，屏幕圆半径=物理半径×1.2；直线距离覆盖不表示15分钟可达、无线信号可靠性或可服务容量。
- 页脚明确：“模拟业务数据 · 空间示意不代表实际服务或运营结果”。
```
