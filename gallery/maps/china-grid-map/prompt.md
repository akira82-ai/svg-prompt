- 六大地理区块（东北 / 华北 / 华东 / 华南 / 西南 / 西北）按大致方位排布为圆角色块组，每块内列 3–5 个省份小方块
- 省份按 模拟值（非GDP） 分四档填色（深蓝到浅灰），图例四档
- 右侧 TOP5 省份排行（广东 / 江苏 / 山东 / 浙江 / 河南）带数值条
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
