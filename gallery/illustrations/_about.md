# 插画与场景 · illustrations

通过人物、设备、环境与概念场景表达内容。15个作品按概念叙事 → 未来场景 → 自然小景 → 主题贴纸排列。

**收录标准**：完整的科技概念插画、人物协作、设备、城市、自然场景与插画套件。主体与叙事优先，静态画面独立成立；不把科幻效果当科学仿真，不把园区场景当导航地图。品牌Logo应用归品牌与排版，完整交互界面归界面与组件。

**视觉规则**：概念组采用清晰的几何色块，未来组用结构与光影建立深度，自然组采用柔和色彩。统一1400×900画幅、中英文名称与画面裁切；每个作品保持SVG、提示词、元数据三件套对应。

**动效规则**：仅全息、能源装置、日出、雪景球与篝火有环境动效，6–8秒缓变；主体不闪烁、不永久隐藏。减少动效或CSS失效时显示同一完整静态场景。
