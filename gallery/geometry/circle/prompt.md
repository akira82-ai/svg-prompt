# 圆 circle `静态` `2D`

分类：[几何与生成艺术](../_about.md)

<img src="index.svg" width="720" alt="圆 circle">

```
用 SVG 画一张"圆"教学图：
- 左卡一个大圆：画出圆心十字线、半径引线，标注 cx / cy / r 三个属性
- 中卡一组同心圆：半径从大到小嵌套，圆心不动只改 r
- 右卡展示三种状态：上排两个圆（蓝实心、红纯描边），下方居中一个半透明紫圆 #9b59f5（opacity 0.4），左卡底部附完整代码标注
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，主题色蓝 #4f8ef7 与红 #f65e5e
```
