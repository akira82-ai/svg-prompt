# 折线 polyline `静态` `2D`

分类：[几何与生成艺术](../_about.md)

<img src="index.svg" width="720" alt="折线 polyline">

```
用 SVG 画一张"折线"教学图：
- 左卡一条 5 个顶点的折线：每个顶点画小圆点并标注序号，首段叠一条 40% 透明灰色虚线，强调 polyline 开放不闭合
- 右卡一条上升趋势的数据折线雏形（另一颜色、圆头拐角），底部配两行应用场景说明
- 注明 fill="none" 防止开放折线出现怪异填充
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，主题色橙 #f5a83c 与青 #38b8c9
```
