# 星形与花形 `静态` `2D`

分类：[几何与生成艺术](../_about.md)

<img src="index.svg" width="720" alt="星形与花形">

```
用 SVG 画一张"星形与花形"教学图：
- 四张卡片：五角星（橙 #f5a83c）、六角星（红 #f65e5e）、八角星（紫 #9b59f5）——外半径 R 与内半径 r 交替取点连成，分别标注 R/r 数值
- 第四张是五瓣圆角花瓣花（粉 #f06292）：采用r(θ)=R(0.76+0.24cos(n(θ+π/2)))，n=5；下方n=6；θ从−π/2采样一整圈，360段闭合折线逼近平滑花瓣
- 下方宽卡片放一朵六瓣花，右侧三行说明 r 大小与花型胖瘦、直线与曲线的区别
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，主题色橙 #f5a83c 与粉红
```
