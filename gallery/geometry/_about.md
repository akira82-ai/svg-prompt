# 几何与生成艺术 · geometry

几何构成、参数曲线、空间分区、递归图案与抽象形变。18个作品按基础构成 → 对称与排列 → 参数线迹 → 分区与纹样 → 递归和空间 → 形变排列。

**收录标准**：以生成规则产生完整的艺术构图。属性教程不拆成作品；公式推导与机制教学归科学与原理，用作平铺底图的作品归背景与材质。

**维护规则**：统一1400×900画幅与中英文名称；几何、提示词、元数据对应，公式与随机种子可复现。沃罗诺伊按最近点距离计算；三角网格明确为规则网格扰动后分割，不冒称Delaunay；流场是数学方向函数，不是流体仿真；黄金角排列不标未经验证的螺旋计数。

**动效规则**：分形树只生长一次并保留全部枝干；两张形变作品共用对应顶点骨架，12秒平稳循环。减少动效时显示完整快照，CSS或SMIL失效也有完整基础图。等距体块由2D矢量表现，不等于真实3D模型。
