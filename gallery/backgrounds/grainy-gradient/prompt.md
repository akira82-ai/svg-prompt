# 噪点渐变 `静态` `2D`

分类：[背景与材质](../_about.md)

<img src="index.svg" width="720" alt="噪点渐变">

```
用 SVG 画一张"噪点渐变"材质样张：
- 满版蓝紫对角渐变（标题下一行副标题），上面叠一层半透明 feTurbulence 噪声（baseFrequency=0.7），形成细腻颗粒
- 左下角放一张对比小卡：同渐变"无噪点"与"有噪点"两块并排
- 右下角参数卡标注三行：baseFrequency 0.7 / 叠加透明度 0.45 / 色矩阵（白色 + alpha 0.55）
- 标题白字在左上，画布 1200×800 满版
```
