# 背景与材质 · backgrounds

服务页面、海报和视觉构图的纹理、图案、渐变与光影。24张按渐变与光影 → 平铺纹理 → 玻璃与金属 → 自然材质 → 环境动效排列。

**收录标准**：主角是可复用的表面、背景与光影，不以道具、代码卡和参数标签占据样张。几何艺术归几何与生成艺术，叙事场景归插画与场景。材质是视觉模拟，不宣称物理渲染和材料性能。

**使用规则**：1400×900展示图中样张区域为x64..1336、y190..810；提取样张组时保留其defs、裁切与引用，移除外围标题。只有科技网格、几何平铺、织物、碳纤维属于无缝pattern，其余是固定构图；滤镜失效时部分纹理简化。深浅底与正文的对比需按实际排版另测。

**维护规则**：保留SVG、提示词与元数据三件套，中英文名称一致；随机种子固定29；磨砂玻璃用同一底图的清晰副本与局部模糊副本，不依赖网页backdrop-filter。不得把平纹编织称作斜纹、把噪声称作实测年轮、把金色镜面称作24K纯金。

**动效规则**：6张环境动效仅作8–10秒低频高光缓变或12px轻移，CSS失效、减少动效时有完整静态画面。不改变纹理seed，不闪烁，不隐藏正文。
