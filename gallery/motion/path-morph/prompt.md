# 变形记 Morph `SMIL 动效` `2D`

```
用 SVG 做"路径形变动画"四宫格（深色 1200×800 版式，每卡下配小图例与等宽字注释）：
- 几何三态：正方形（控制点共线）⇄ 圆 ⇄ 菱形，同一副 8 锚点骨架，9s 循环
- 图形开花：圆 → 五角星 → 爱心，同一副 10 锚点骨架，12s 多关键帧循环
- 字母变形 B ⇄ W：金红渐变粗描边，keyTimes 控制停顿
- 状态切换 ✓ ⇄ ✗：勾叉形变与描边色绿 #3ecf8e ⇄ 红 #f65e5e 同步渐变，配 ALL SYSTEMS GO / INCIDENT IN PROGRESS 文字切换
- 铁律写进要求：任何两条 path 的命令数与锚点数完全相同
```
