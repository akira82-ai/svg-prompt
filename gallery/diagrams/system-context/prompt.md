用 SVG 制作“系统上下文图”：人与外部系统 / 被设计系统的边界。
- 画布1400×900，背景#0d1724；标题34px、组件名17–22px、说明15–16px；语义配色：调用蓝、事件橙、数据绿、控制红、关联灰。
- 重点表达：“只解释谁使用系统、系统依赖谁；不混入内部部署细节”。
- 系统边界仅包围AI应用；用户、管理员、模型服务、知识源和身份提供方均在外部。
- 节点表示人与系统，不出现Pod、数据库表或内部微服务；箭头表示主要交互，响应可在接口语义中说明。
- 先列节点坐标与端口；端口l/r/t/b分别为矩形左/右/上/下中点，菱形为对应顶点。按下列坐标绘制：
  - user: 终端用户；说明["提交问题 / 阅读答案"]；(x,y,w,h)=(100,450,220,90)；形状box。
  - app: AI 应用系统；说明["权限、编排、结果交付"]；(x,y,w,h)=(560,435,280,120)；形状box。
  - model: 外部模型服务；说明["生成接口"]；(x,y,w,h)=(1040,410,230,100)；形状box。
  - search: 企业知识源；说明["授权文档接口"]；(x,y,w,h)=(1040,600,230,90)；形状box。
  - identity: 身份提供方；说明["令牌与身份校验"]；(x,y,w,h)=(560,680,280,70)；形状box。
  - admin: 管理员；说明["配置与审计"]；(x,y,w,h)=(100,650,220,90)；形状box。
- 连线先画、节点后画，线不穿过无关节点。下列方向、条件与折点必须一致：
  - user → app；call；标签“提交问题 / 获取结果”；条件“”；折点[[320, 495.0], [560, 495.0]]；有箭头。
  - app → model；call；标签“生成请求”；条件“”；折点[[840, 495.0], [950, 495], [950, 460], [1040, 460.0]]；有箭头。
  - app → search；data；标签“读取授权内容”；条件“”；折点[[840, 495.0], [965, 495], [965, 645], [1040, 645.0]]；有箭头。
  - app → identity；control；标签“校验身份”；条件“”；折点[[700.0, 555], [700.0, 680]]；有箭头。
  - admin → app；control；标签“管理配置”；条件“”；折点[[320, 695.0], [430, 695], [430, 495], [560, 495.0]]；有箭头。
- 页脚注明：“概念结构示意 · 不代表完整生产部署或真实运行状态”。
