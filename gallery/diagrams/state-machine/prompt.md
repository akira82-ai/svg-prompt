```
用 SVG 制作“异步任务状态机”：排队、执行、退避与终态；最多 3 次尝试。
- 画布1400×900，背景#f3f5f7；标题34px、组件名17–22px、说明15–16px；语义配色：调用蓝、事件橙、数据绿、控制红、关联灰。
- 重点表达：“成功、失败、取消都是终态；重试有明确预算与条件”。
- 六个状态，attempt从1开始且最多3次；失败包含工具/执行错误和结果校验失败。
- 排队与退避可取消；执行中的取消只有在执行方停止并确认后才能进入已取消，不能只因客户端断开连接就宣称已取消。
- 成功/失败/已取消均为终态，无出边。失败可重试与不可重试条件不重叠。
- 先列节点坐标与端口；端口l/r/t/b分别为矩形左/右/上/下中点，菱形为对应顶点。按下列坐标绘制：
  - pending: 排队中；说明["等待调度"]；(x,y,w,h)=(100,335,220,80)；形状box。
  - running: 执行中；说明["失败包含校验失败"]；(x,y,w,h)=(490,335,220,80)；形状box。
  - success: 成功；说明["结果通过校验"]；(x,y,w,h)=(960,290,220,80)；形状box。
  - failed: 失败；说明["保留最后错误"]；(x,y,w,h)=(960,490,220,80)；形状box。
  - retry: 退避等待；说明["准备下一次尝试"]；(x,y,w,h)=(490,620,220,80)；形状box。
  - cancelled: 已取消；说明["任务已停止"]；(x,y,w,h)=(100,620,220,80)；形状box。
- 连线先画、节点后画，线不穿过无关节点。下列方向、条件与折点必须一致：
  - pending → running；call；标签“调度成功”；条件“”；折点[[320, 375.0], [490, 375.0]]；有箭头。
  - running → success；call；标签“输出有效”；条件“success”；折点[[710, 375.0], [840, 375], [840, 330], [960, 330.0]]；有箭头。
  - running → failed；control；标签“失败且 attempt ≥ 3”；条件“failure and attempt>=3”；折点[[710, 375.0], [840, 375], [840, 530], [960, 530.0]]；有箭头。
  - running → retry；control；标签“失败且 attempt < 3”；条件“failure and attempt<3”；折点[[600.0, 415], [600.0, 620]]；有箭头。
  - retry → running；control；标签“退避结束 · attempt + 1”；条件“backoff complete”；折点[[710, 660.0], [775, 660], [775, 375], [710, 375.0]]；有箭头。
  - pending → cancelled；control；标签“取消请求”；条件“cancel”；折点[[210.0, 415], [210.0, 620]]；有箭头。
  - running → cancelled；control；标签“收到取消且任务已停止”；条件“cancel acknowledged”；折点[[490, 375.0], [380, 375], [380, 660], [320, 660.0]]；有箭头。
  - retry → cancelled；control；标签“取消”；条件“cancel”；折点[[490, 660.0], [320, 660.0]]；有箭头。
- 页脚注明：“概念结构示意 · 不代表完整生产部署或真实运行状态”。
```
