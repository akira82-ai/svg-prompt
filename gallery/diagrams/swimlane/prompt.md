```
用 SVG 制作“跨角色泳道流程”：需求方 / 生成系统 / 审核方。
- 画布1400×900，背景#f3f5f7；标题34px、组件名17–22px、说明15–16px；语义配色：调用蓝、事件橙、数据绿、控制红、关联灰。
- 重点表达：“泳道表达职责，箭头表达交接；审核失败必须返回修正”。
- 三条纵向泳道，节点只能放在其负责角色的泳道里；需求方提交并接收，生成系统生成/自检/修正，审核方判断。
- 审核是/否分别交付与反馈，修正后回到生成；箭头跨泳道处明确交接内容。
- 先列节点坐标与端口；端口l/r/t/b分别为矩形左/右/上/下中点，菱形为对应顶点。按下列坐标绘制：
  - request: 提交需求；说明["目标与验收条件"]；(x,y,w,h)=(160,325,220,70)；形状box。
  - generate: 生成初稿；说明["依据验收清单"]；(x,y,w,h)=(570,325,220,70)；形状box。
  - preview: 提交预览；说明["作品与检查结果"]；(x,y,w,h)=(570,500,220,80)；形状box。
  - check: 审核通过？；说明[]；(x,y,w,h)=(980,490,220,100)；形状diamond。
  - revise: 修正差异；说明["保留审核意见"]；(x,y,w,h)=(570,680,220,70)；形状box。
  - deliver: 接收交付；说明["作品与提示词"]；(x,y,w,h)=(160,680,220,70)；形状box。
- 连线先画、节点后画，线不穿过无关节点。下列方向、条件与折点必须一致：
  - request → generate；call；标签“需求交接”；条件“”；折点[[380, 360.0], [570, 360.0]]；有箭头。
  - generate → preview；call；标签“渲染与自检”；条件“”；折点[[680.0, 395], [680.0, 500]]；有箭头。
  - preview → check；call；标签“送审”；条件“”；折点[[790, 540.0], [980, 540.0]]；有箭头。
  - check → revise；control；标签“否：差异反馈”；条件“否”；折点[[980, 540.0], [925, 540], [925, 715], [790, 715.0]]；有箭头。
  - revise → generate；control；标签“修正后重送”；条件“”；折点[[570, 715.0], [515, 715], [515, 360], [570, 360.0]]；有箭头。
  - check → deliver；data；标签“是：交付归档”；条件“是”；折点[[1090.0, 590], [1090, 785], [270, 785], [270.0, 750]]；有箭头。
- 页脚注明：“概念结构示意 · 不代表完整生产部署或真实运行状态”。
```
