用 SVG 制作“RAG：索引与查询两条路径”：离线知识处理 / 在线授权检索与生成。
- 画布1400×900，背景#0d1724；标题34px、组件名17–22px、说明15–16px；语义配色：调用蓝、事件橙、数据绿、控制红、关联灰。
- 重点表达：“权限过滤先于重排；证据不足应拒答，引用需要可追溯”。
- 离线文档→切分→嵌入→向量元数据保留source_id、chunk_id和ACL；文档/查询使用兼容的同一编码器。
- 在线query与scope→查询嵌入→ACL过滤检索→重排→生成/拒答→答案与来源；授权scope不能在嵌入后丢失，不能只在生成之后做权限过滤。
- 证据不足走拒答分支；来源ID供引用核查，引用存在不自动保证答案正确。
- 先列节点坐标与端口；端口l/r/t/b分别为矩形左/右/上/下中点，菱形为对应顶点。按下列坐标绘制：
  - documents: 授权文档；说明["source_id / ACL"]；(x,y,w,h)=(90,330,220,90)；形状box。
  - chunks: 文档切分；说明["chunk_id / source_id"]；(x,y,w,h)=(430,330,220,90)；形状box。
  - embedding: 文档嵌入；说明["同一编码器"]；(x,y,w,h)=(770,330,220,90)；形状box。
  - vectors: 向量与元数据；说明["vector / ID / ACL"]；(x,y,w,h)=(1110,330,220,90)；形状box。
  - query: 查询与权限；说明["query + scope"]；(x,y,w,h)=(60,605,175,95)；形状box。
  - qembed: 查询嵌入；说明["保留授权 scope"]；(x,y,w,h)=(280,605,175,95)；形状box。
  - retrieve: 过滤检索；说明["先 ACL 后 top-k"]；(x,y,w,h)=(500,605,175,95)；形状box。
  - rerank: 证据重排；说明["证据排序"]；(x,y,w,h)=(720,605,175,95)；形状box。
  - generate: 生成与拒答；说明["不凭空补证据"]；(x,y,w,h)=(940,605,175,95)；形状box。
  - answer: 答案与引用；说明["source_id 可追溯"]；(x,y,w,h)=(1160,605,175,95)；形状box。
- 连线先画、节点后画，线不穿过无关节点。下列方向、条件与折点必须一致：

  - query → qembed；call；标签“”；条件“”；折点[[235, 652.5], [280, 652.5]]；有箭头。
  - qembed → retrieve；call；标签“”；条件“”；折点[[455, 652.5], [500, 652.5]]；有箭头。
  - retrieve → rerank；call；标签“”；条件“sufficient evidence”；折点[[675, 652.5], [720, 652.5]]；有箭头。
