用 SVG 制作“质量决策与有限重试”：渲染检查、提示词对齐、修复与退出。
- 画布1400×900，背景#f3f5f7；标题34px、组件名17–22px、说明15–16px；语义配色：调用蓝、事件橙、数据绿、控制红、关联灰。
- 重点表达：“两次判断都有是／否分支；达到重试上限必须停止”。
- 渲染与提示词对齐两判断必须完整覆盖是/否，失败进入定位修复，不直接交付。
- 最多3次重试，retry<3返回生成且次数加1，retry>=3停止报告；不要吞掉渲染或校验失败。
- 先列节点坐标与端口；端口l/r/t/b分别为矩形左/右/上/下中点，菱形为对应顶点。按下列坐标绘制：
  - start: 开始；说明[]；(x,y,w,h)=(100,350,150,70)；形状pill。
  - generate: 生成 SVG；说明[]；(x,y,w,h)=(370,350,190,70)；形状box。
  - render: 渲染通过？；说明[]；(x,y,w,h)=(750,335,190,100)；形状diamond。
  - review: 视觉终审；说明[]；(x,y,w,h)=(1100,350,190,70)；形状box。
  - aligned: 提示词对齐？；说明[]；(x,y,w,h)=(750,580,190,100)；形状diamond。
  - publish: 归档交付；说明[]；(x,y,w,h)=(1100,595,190,70)；形状pill。
  - fix: 定位与修复；说明[]；(x,y,w,h)=(385,715,200,70)；形状box。
  - stop: 停止并报告；说明[]；(x,y,w,h)=(100,715,160,70)；形状pill。
- 连线先画、节点后画，线不穿过无关节点。下列方向、条件与折点必须一致：
  - start → generate；call；标签“”；条件“”；折点[[250, 385.0], [370, 385.0]]；有箭头。
  - generate → render；call；标签“”；条件“”；折点[[560, 385.0], [750, 385.0]]；有箭头。
  - render → review；call；标签“是”；条件“是”；折点[[940, 385.0], [1100, 385.0]]；有箭头。
  - render → fix；control；标签“否”；条件“否”；折点[[845.0, 435], [845, 505], [650, 505], [650, 750], [585, 750.0]]；有箭头。
  - review → aligned；call；标签“检查一致性”；条件“”；折点[[1195.0, 420], [1195, 535], [845, 535], [845.0, 580]]；有箭头。
  - aligned → publish；call；标签“是”；条件“是”；折点[[940, 630.0], [1100, 630.0]]；有箭头。
  - aligned → fix；control；标签“否”；条件“否”；折点[[845.0, 680], [845, 750], [585, 750.0]]；有箭头。
  - fix → generate；control；标签“重试次数 < 3”；条件“retry<3”；折点[[385, 750.0], [310, 750], [310, 385], [370, 385.0]]；有箭头。
  - fix → stop；control；标签“≥ 3 次”；条件“retry>=3”；折点[[385, 750.0], [260, 750.0]]；有箭头。
- 页脚注明：“概念结构示意 · 不代表完整生产部署或真实运行状态”。
