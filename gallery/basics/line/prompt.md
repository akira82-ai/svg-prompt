# 直线 line `静态` `2D`

<img src="index.svg" width="720" alt="直线 line">

## 提示词

```
用 SVG 画一张"直线"教学图：
- 第一张卡片：4 条由细到粗的直线（stroke-width 2 / 6 / 12 / 20）
- 第二张卡片：同粗细的三条线对比线帽——butt 平头、square 方头、round 圆头，属性标在线下方居中
- 第三张卡片：5 条不同颜色的线
- 下方宽卡片：一条斜线两端画端点圆并标注 (x1,y1) / (x2,y2)，右侧说明"线没有内部，只有描边"
- 结论行：虚线、连接线、坐标轴都从 line 出发
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，多色线用蓝红绿紫橙
```
