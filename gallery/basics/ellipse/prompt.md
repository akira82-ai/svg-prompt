## 提示词

```
用 SVG 画一张"椭圆"教学图：
- 上排 4 张卡片展示比例谱系：rx:ry 从 1:1 正圆逐渐压扁到扁椭圆，每张标注 rx / ry 数值
- 下方宽卡片展示一个旋转 -24° 的椭圆，标注 transform="rotate(-24)"，旁边三行说明要点
- 结论行：椭圆 = 圆的压缩体，行星轨道与涟漪的第一步
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，主题色绿 #3fb98f
```
