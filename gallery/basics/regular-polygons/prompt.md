# 正多边形家族 `静态` `2D`

<img src="index.svg" width="720" alt="正多边形家族">

## 提示词

```
用 SVG 画一张"正多边形家族"教学图：
- 上排 5 张卡片：正三、四、五、六、八边形，全部相同外接圆半径、顶点朝上，标注边数 n=3 到 n=8
- 下方宽卡片：圆角变体——正五边形用粗描边 + stroke-linejoin="round" 磨圆角，右侧三行顶点公式说明
- 结论行：n 越大越接近圆，多边形与圆之间只隔着一条顶点公式
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，五边形依次用红橙绿青蓝
```
