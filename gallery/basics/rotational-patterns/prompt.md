# 旋转复制组合 `静态` `2D`

<img src="index.svg" width="720" alt="旋转复制组合">

## 提示词

```
用 SVG 画一张"旋转复制组合"教学图，三张卡片：
- 齿轮：12 个齿矩形绕圆心每 30° 旋转复制，加圆身与中孔，标注"12 齿 × 30°"
- 六瓣花：6 个椭圆花瓣每 60° 旋转复制，加中心圆，标注"6 瓣 × 60°"
- 太阳：8 条圆头射线每 45° 旋转复制，标注"8 射线 × 45°"
- 下方宽卡片三行说明套路：单元写一次 + rotate(角度 圆心) 复制 N 份、角度 = 360°/N
- 结论行：旋转复制 = 单元 × 360°/N，雪花徽章 loading 都是它的变体
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片分格，主题色橙与粉红
```
