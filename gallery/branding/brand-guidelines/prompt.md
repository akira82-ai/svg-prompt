# 品牌规范页 `静态` `2D`

分类：[品牌与排版](../_about.md)

<img src="index.svg" width="720" alt="品牌规范页">

```
用 SVG 画一张"品牌规范页"（Brand Guidelines 单页）：
- 左上"安全距离"：星芒 Logo 外围虚线框，四边标注 x（Logo 高度的一半）
- 中上"最小尺寸"：一大一小两个 Logo（64px / 24px）标注最小可用品
- 右上"错误示范"三个：拉伸变形的 Logo、改变颜色的 Logo、压在杂色底上的 Logo，各盖红色禁止圈（圆+斜线）
- 底部条：色板五个小色块 + 字体名"PingFang SC / SF Mono"
- 整页像一页真正的 Brand Book：分区标题小字大写、留白充分
- 画布 1200×800 浅蓝灰背景，白色大圆角卡片承载全部内容
```
