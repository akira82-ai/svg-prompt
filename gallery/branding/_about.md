# 品牌与排版 · branding

品牌识别、字标、文字构成与传播版式，共24张。按品牌识别5张 → 字体与排版5张 → 编辑与传播8张 → 应用物料4张 → 品牌动效2张排列。

**收录标准**：品牌基础共用几何资产与色彩规则；排版明确阅读路径，应用物料保持不同画幅的比例与信息层级。独立装饰变形和故障特效不作为本分类主线。

**三套示例品牌**：NOVA技术工具品牌使用固定矢量图标与几何字标、蓝色和深色；FIELD编辑出版品牌使用暖纸色、红色强调与中英文字体搭配；LOAM生活消费品牌使用土色与地平线标识。名称、产品、机构、人物与文案均为虚构示例，不暗示真实发布或认证。

**构形与排版**：NOVA标识基于6×6网格，安全留白为高度1/6，字标宽高266:60。字阶与行高为示例规范；系统字体与回退会影响混排字面。最小尺寸24px仅为示例预设，不能视为经过载体验证。

**物料边界**：纸张比例、名片与社媒逻辑尺寸明确，展示图按比例缩放；包装切线、折线、出血与安全区分别表达。包装结构未经锁底、插舌、纸厚和生产工艺验证，不能直接作为生产刀版。统计卡由全库元数据生成；对比版式保留格式、压缩、嵌入和环境条件。

**动效与展示**：文案揭示和片头只播放一次，终帧保留完整品牌信息；减少动效显示完整静态快照。作品与首页显示中英文名称，时间和空间形式保留在元数据中。

**维护**：修改 `scripts/build-branding.py` 后生成三件套，运行 `scripts/check-branding.py` 与首页生成脚本，并检查全部浏览器布局、字体可读性和减少动效。生成脚本不会删除目录；本次获准移除4个偏装饰或重复条目，历史可从Git追溯。
