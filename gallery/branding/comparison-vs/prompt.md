# 对比信息图 `静态` `2D`

分类：[品牌与排版](../_about.md)

<img src="index.svg" width="720" alt="对比信息图">

```
用 SVG 画一张"对比信息图"：
- 左右两大版式：左"矢量 SVG"（蓝系）、右"位图 PNG"（灰系），中央红色 VS 圆形徽章
- 五个维度左右对照：缩放（矢量轮廓清晰 / 受像素数限制）、体积（复杂度决定 / 尺寸与压缩决定）、可编辑（文本级 / 像素级）、动画（原生 / 需序列帧）、索引（文字提取取决于嵌入方式 / 可配alt或OCR）
- 每维度一行，中央维度名
- 画布 1200×800 浅蓝灰背景，白色圆角图表卡
```
