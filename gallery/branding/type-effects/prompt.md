# 文字特效四连 `静态` `2D`

分类：[品牌与排版](../_about.md)

<img src="index.svg" width="720" alt="文字特效四连">

```
用 SVG 画一张"品牌文字特效"展示图，四张卡片各一种"NOVA"大字效果：
- 描边字：无填充、深色细描边（优雅线框感）
- 渐变字：蓝紫渐变直接填充文字
- 镂空字：一块渐变色板被文字形状抠空（mask），字内透出白色背景
- 霓虹字：深色卡片底，紫色模糊光晕文字叠一层清晰的白色文字（feGaussianBlur）
- 每张卡下方标注特效名与实现关键词
- 画布 1200×800 浅蓝灰背景，白色圆角卡片（霓虹卡为深色底）
```
