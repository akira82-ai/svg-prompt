```
用 SVG 画一张"App 图标"展示图：
- 上排四张并排卡各含一枚大图标（圆角约 22% 的方形容器）：星芒（蓝紫渐变+白星芒）、音乐（青绿渐变+白色音符：圆点+符杆+符尾）、天气（橙红渐变+白色太阳：圆+8短线）、日历（深色底+白色日历框与两个挂钩）
- 底部通栏卡：左侧 iOS 图标网格模板（大方框+内切圆+对角线+中心圆），右侧三行说明（含导出尺寸 1024×1024）
- 每枚图标下方标名称
- 画布 1200×800 浅蓝灰背景，白色圆角卡片，渐变明快
```
