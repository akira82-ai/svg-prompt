# 图标与符号 · icons

简洁、可识别、可复用的功能图标与状态符号。12个作品按构形基础 → 风格系统 → 产品语义 → 场景应用 → 状态动效排列。

**收录标准**：图标构形、线性/实心/双色系统、小尺寸适配、箭头、状态、文件、科技产品、App与导视符号。完整品牌标志归品牌与排版，完整界面与操作流程归界面与组件。

**维护规则**：同类符号统一24单位视图、笔触、端点与留白；以`symbol/use`复用、`currentColor`控制颜色。实心图标使用闭合轮廓，不能简单把线性图标填黑。1:1尺寸需原图100%查看，缩略图不是实际尺寸。所有作品保留中英文名字，提示词与SVG对应。

**应用边界**：光学校正仍需实际载体测试；App容器为示例圆角矩形；导视作品未经公共标识标准认证。动效只播放一次，保持完整终态，减少动效时直接显示终态。
