# 消息提示条 `静态` `2D`

<img src="index.svg" width="720" alt="消息提示条">

```
用 SVG 画一张"消息提示条规格图"：
- 四条全宽横幅纵向排列：成功（浅绿底 + 绿色圆形对勾图标）、错误（浅红底 + 红色圆形叉）、警告（浅橙底 + 橙色圆形叹号）、信息（浅蓝底 + 蓝色圆形 i）
- 每条横幅左侧圆形图标 + 右侧两行文字：粗标题（如"操作成功"）+ 小字说明
- 图标白色刻在彩色圆上
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片，语义色：成功 #3fb98f、错误 #f65e5e、警告 #f5a83c、信息 #4f8ef7
```
