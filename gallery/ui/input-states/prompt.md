# 输入框状态 `静态` `2D`

分类：[界面与组件](../_about.md)

<img src="index.svg" width="720" alt="输入框状态">

```
用 SVG 画一张"输入框状态规格图"：
- 四个输入框纵向排列，每个上方有小标签：
- 默认态：灰描边 + 灰色占位文字"请输入内容"
- 聚焦态：蓝色 2.5px 描边 + 深色已输入文字 + 末尾一根蓝色光标竖线
- 错误态：红色描边 + 已输入文字 + 框下方一行红色提示"请输入有效的邮箱地址"
- 禁用态：灰底、灰字"已禁用"、整体置灰
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片，主色 #4f8ef7、错误色 #f65e5e
```
