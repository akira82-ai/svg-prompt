# 渐变与玻璃质感 `静态` `2D`

分类：[界面与组件](../_about.md)

<img src="index.svg" width="720" alt="渐变与玻璃质感">

```
用 SVG 画一张"渐变与玻璃质感"设计展示图，四个区块：
- 浅色渐变背景上漂浮两团彩色光斑（radialGradient 圆形）
- 品牌图标：圆角方形渐变底座 + 中心四角星 path + feDropShadow 彩色光晕
- 渐变文字：大标题文字 fill="url(#textGrad)" 直接引用线性渐变
- 毛玻璃卡片：半透明白色圆角矩形（fill-opacity 0.55）+ 1.5px 白描边（opacity 0.9）叠在彩色背景上
另有渐变胶囊按钮组（3 个）与一排圆形小图标。画布 1200×800，浅色背景。
```
