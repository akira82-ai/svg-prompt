```
用 SVG 制作“产品引导”，用于状态与过程反馈。
- 画布1400×900；浅色产品界面，背景#eef2f7、卡片#ffffff、正文#1d2e46、辅助文字#596b82、主色#2467d5；34px标题、15–19px正文、圆角8–12px、8px间距基准。
- 顶部作品标题与分组说明，内容位于x80..1320、y210..820；底部标注界面原型、模拟内容和非真实交互。
- 新手引导包含建立项目、邀请成员、添加资料三个步骤；当前第一步，允许稍后继续。
- 文字与示例值包含：["SVG / PRODUCT INTERFACES", "DEMO · 状态示意", "产品引导", "状态与过程反馈 / 产品场景与状态设计", "界面原型 · 模拟内容 · 控件状态不代表实际交互", "SVG-PROMPT", "ATLAS", "WORKSPACE / DEMO", "概览", "项目", "知识库", "林", "个人工作区", "演示账号", "欢迎加入工作区", "新建项目", "开始使用 / 1 共 3 步", "1", "建立你的第一个项目", "集中管理任务、文件与讨论", "2", "邀请团队成员", "协作之前明确每个人的角色", "3", "添加知识资料", "为搜索与引用准备可追溯来源", "继续引导", "可以跳过引导，稍后从帮助中心继续。"]。
- 控件由SVG图形展示状态，不添加真实网络、登录、支付或权限操作；模拟场景不能宣称实时服务。
```
