# 电商首页 `静态` `2D`

<img src="index.svg" width="720" alt="电商首页">

```
用 SVG 画一张"电商 App 首页"高保真原型，一台手机：
- 顶部搜索框（放大镜图标 + "秋季新品" 占位 + 扫码图标）
- 渐变橙红秒杀 Banner："限时秒杀 · 全场 8 折起" + "立即抢购"白色小胶囊按钮
- 四个圆形分类入口（穿着 / 数码 / 美妆 / 家居），浅色圆底 + 简笔图标
- "猜你喜欢"区：横向商品卡（浅色渐变图区 + 两行标题 + 红色价格 + 已售数量），第三张被屏幕边缘裁掉示意滑动
- 底部 Tab 栏 5 项：首页（蓝色激活）/分类/购物车（带数字角标）/订单/我的
- 状态栏 9:41、Home 条等整机细节齐全
- 画布 1200×800 浅蓝灰背景，价格用红 #f65e5e，主色 #4f8ef7
```
