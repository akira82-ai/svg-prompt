# 加载器三连 `SMIL 动效` `2D`

分类：[界面与组件](../_about.md)

<img src="index.svg" width="720" alt="加载器三连">

```
用 SVG 做一张"加载动效规格图"：
- 三张卡片各一种加载器：
- 旋转圆弧：灰色圆轨道 + 蓝色圆头弧线绕圆心匀速旋转（animateTransform rotate）
- 三点跳动：三个圆点依次上下弹跳，begin 依次错开 0.15s
- 脉冲圆环：圆环半径由小变大、透明度由 1 到 0 循环扩散，中心一个实心点
- 每张卡片下方标注名称与时长
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片，主色 #4f8ef7
```
