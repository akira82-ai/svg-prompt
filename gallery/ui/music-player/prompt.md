# 音乐播放器 `SMIL 动效` `2D`

<img src="index.svg" width="720" alt="音乐播放器">

```
用 SVG 做一张"音乐 App"高保真原型，两台手机：
- 屏一深色播放页：深蓝夜色背景，大尺寸渐变唱片（圆角方形内嵌同心圆），歌名"夜航 Starry Flight"+ 歌手"磊叔"，白色进度条走到 60%（两端时间 1:24 / 3:56），控制行：随机/上一首/白色大圆播放键（内嵌深色三角）/下一首/循环
- 屏二播放列表（浅色）：大标题"播放列表"，5 首歌（渐变封面缩略块 + 歌名 + 歌手 + 时长），第一首播放中：蓝色歌名 + 三根律动均衡器条替代时长（SMIL 循环起伏），底部悬浮迷你播放条
- 状态栏、Home 条等整机细节齐全
- 画布 1200×800 浅蓝灰背景，深色屏用 #141c28，主色 #4f8ef7
```
