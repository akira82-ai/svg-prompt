# 界面与组件 · ui

面向产品设计的控件、状态反馈、数据操作、AI 工作台和完整页面，共 60 张。按输入与基础组件12张 → 导航与检索10张 → 状态与过程反馈13张 → 数据操作与指标6张 → AI产品界面5张 → 协作与业务操作6张 → 完整工作台与特色场景8张排序。

**收录标准**：每张解决明确的界面表达问题；基础组件展示状态，复杂操作保留上下文，完整页面包含关键操作。SVG 控件是状态原型，不具有真实交互、网络、支付、授权或登录能力。

**视觉与状态**：协调的浅色产品界面与深色专业工作台；明确标题、辅助说明和操作层级。聚焦用独立外框，错误说明修正方式，禁用说明原因；消息与服务状态结合文字、符号和颜色。品牌、用户、文档、模型及业务数字均为模拟内容。

**动画约束**：区分入场、状态转换和强调。确定进度与数值同步，不确定进度不显示百分比；告警内容持续可读。静态与动画经营盘、运维盘共用快照；巡检与Agent强调不改变服务状态、不越过确认步骤。减少动效保留原型主体并显示明确静态快照。

**指标约束**：金额、次数、百分比与百分点分开；经营盘每日值合计匹配KPI，客单价由金额/订单计算。日历与日期一致。波形解析器使用同一模拟信号计算幅值谱，不以随机频谱柱暗示真实测量；HUD刻度与固定航向对应，不用装饰旋转改变读数含义。

**维护**：修改 `scripts/build-ui.py`，运行生成脚本、`scripts/check-ui.py` 和 `scripts/build-readme.mjs`，检查全部图的浏览器布局、动画时刻及减少动效模式。保留作品沿用原目录；此次明确移除9个装饰性或重复条目，历史版本可从Git追溯，生成脚本不会执行删除。

**标签**：时间与空间形式分别使用 `time`、`space`，具体技术用 `tech`；每张图只有一个主分类。
