# 标签页与分段控件 `静态` `2D`

<img src="index.svg" width="720" alt="标签页与分段控件">

```
用 SVG 画一张"标签页规格图"：
- 上卡：下划线式标签页，4 个页签（首页 / 发现 / 消息 / 我的），第一个激活——蓝色文字 + 3px 圆头蓝色下划线，其余灰色，整行底部一条浅灰基线
- 下卡：胶囊分段控件，灰底圆角容器内两段（日间 / 夜间），激活段是带微阴影的白色胶囊、蓝字
- 标注 激活 active / 未选 inactive
- 画布 1200×800，浅蓝灰背景 #f6f8fb，白色圆角卡片，主色 #4f8ef7
```
